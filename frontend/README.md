# LifeLane Frontend

LifeLane — Intelligent Ambulance Signal Priority System.

A smart, route-aware emergency mobility platform designed to improve ambulance movement through coordinated traffic signal prioritization.

## Simulation environment

Traffic signals and dispatch operations are simulated using SUMO. This demonstration is not connected to live traffic infrastructure.

## Run locally

```bash
pnpm install
pnpm dev
```

Build a production bundle with `pnpm build`.
